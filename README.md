# Cross-Architecture Knowledge Distillation

This capstone research project studies how a Vision Transformer teacher can transfer features and predictions to a smaller MobileNetV2 student for plant leaf disease classification. It uses PyTorch, torchvision, and timm.

## Explore the project

- [`main.py`](main.py) combines the teacher, student, feature projectors, and loss functions into a training pipeline.
- [`dataset.py`](dataset.py) loads images organized by class and builds train, validation, and test splits.
- [`test.py`](test.py) evaluates a saved student checkpoint.
- The [Burmese grape experiments](https://github.com/zoe1410/capstone-knowledge-distillation/tree/Burmese_v4%28Strategy4%29) and [tomato leaf baselines](https://github.com/zoe1410/capstone-knowledge-distillation/tree/TomatoLeaf_VaibhavSolapure) retain their own evaluation code and setup notes.

## Evaluate a student checkpoint

Create a Python environment with a PyTorch build that suits your hardware, then install the project dependencies.

```sh
python -m pip install -r requirements.txt
```

From the repository root, supply an ImageFolder dataset with one subdirectory per class and its matching student checkpoint. Use the original class folder names so `ImageFolder` assigns labels in the same order as the checkpoint. The example paths point to local copies of the inputs.

```sh
python test.py --data-dir assets/burmese_grape_leaf --checkpoint assets/burmese_grape_leaf_student.pth --device cuda:0 --batch-size 32
python test.py --data-dir assets/tomato --checkpoint assets/tomato_student.pth --device cuda:0 --batch-size 32
```

### Verified local run

Evaluation ran on Windows with Python 3.12.4, PyTorch 2.4.1+cu124, torchvision 0.19.1+cu124, scikit-learn 1.5.1, and an NVIDIA GeForce RTX 3050 Ti Laptop GPU. Both datasets were restored from the matching [AgriKD DVC manifests](https://github.com/zoe141004/agrikd-app/tree/cba6965fec9f3423891f8ed68eb733cbec67b2d7/dvc). The evaluator uses a stratified 70/15/15 split with seed 42.

| Dataset | Full dataset | Evaluation split | Correct | Accuracy |
| --- | ---: | ---: | ---: | ---: |
| Burmese grape leaf | 3,090 images, 5 classes | 464 | 405 | 87.28% |
| Tomato leaf | 1,609 images, 10 classes | 242 | 212 | 87.60% |

These scores describe the recovered checkpoints on the split generated by this evaluator. The original training splits were unavailable for comparison, so overlap with training data could not be ruled out.

## Train the distillation model

Provide an image dataset with one subdirectory per class and a compatible five-class teacher checkpoint. Set the dataset directory in the configuration at the end of `main.py`, and set `checkpoint_path` where `TeacherExtractor` is initialized. Run `python main.py` from the repository root. The verified run above evaluated existing student checkpoints. Retraining requires the original teacher checkpoint.

The training inputs and model checkpoints are external artifacts. This portfolio edition preserves the experiment branches and excludes credentials, Python bytecode caches, and bundled copies of the reference paper.

## Reference

The feature projection approach is based on the paper by Liu et al. [Cross-Architecture Knowledge Distillation, ACCV 2022](https://arxiv.org/abs/2207.05273).
